# Gallery 导航中英文切换验证

验证日期：2026-10-08；Windows x64，Rust/C++ 共用 `Gallery/data/navigation.txt`。

导航目录已补齐中文显示名，覆盖全部 109 个可见条目，包括分组、嵌套子项、页脚和组件标题。例如 `Button` → 按钮、`Picker` → 选择器、`TimePicker` → 时间选择器、`DatePicker` → 日期选择器、`ForgePlot` → 专业图表。英文模式恢复目录中的英文名称。
