# 专业图表实现与验收

本任务的目标是提供可直接接入 Slint 的完整专业二维绘图组件，并审查、测试和优化 DataGrid、TreeDataGrid。图表能力对照 [QCustomPlot 2.1.1](https://www.qcustomplot.com/documentation/index.html)，沿用现有共享 Slint 契约以及 Rust/C++ 消费方式。

## 图表能力和证据

| 能力 | 实现要求 | 验收证据 |
|---|---|---|
| 图形 | 折线、阶梯、脉冲、散点样式、参数曲线、基线与系列间填充、分组/堆叠柱、统计箱及离群点、蜡烛/OHLC、二维色图、极坐标曲线 | 数值回归、可见绘图与双端消费者 |
| 坐标 | 四边多轴、多绘图区、线性/正负对数、反向坐标、自动范围、数字/文本/日期时间/时长/π刻度、轴标签 | 映射往返、极值及非法输入、绘图区截图 |
| 误差与色图 | 横纵不对称误差棒、色阶/透明无效单元、色范围与调色板 | 范围覆盖、单元命中和导出 |
| 图元 | 文本、线/箭头、矩形/椭圆、曲线、括号、跟踪点、图片，数据/比例/像素定位、锚点、裁剪、层顺序 | 范围变化前后定位、命中与截图 |
| 交互 | 光标中心缩放、拖动平移、框选缩放、单选/多选、图例显隐、十字线、工具提示、键盘、禁用、选择与坐标回调 | 实际指针/滚轮/按键事件回归 |
| 数据 | 批量替换、追加与有界实时缓冲、刷新节流、可见区裁剪、保留极值的降采样 | 波形峰值/断线回归，10万/100万点性能与空间开销 |
| 交付 | 公共导出、双端绑定、默认轴/样式、独立示例、Gallery、PNG/JPEG/BMP/SVG/PDF导出 | 工作区测试、C++安装后独立工程、导出解码/渲染 |

## 结构

- `ui/types/plot.slint` 定义公共模型、服务和状态；`ui/charts/plot.slint` 管理界面和交互。
- `sdk/common/ForgePlotCore.h/.cpp` 是两端共用的无界面数值、几何、命中和矢量导出引擎，使用明确生命周期的 C ABI。第一方 C++ 不声明 namespace。
- Rust/C++ 适配层转换公共模型，将引擎 SVG 交给 Slint 原生 SVG 图像加载器。图元按系列合并成路径，避免每个采样点创建 UI 元素。
- 原始数据索引保留在降采样结果中，选择回调使用原始索引。图形、坐标、命中与导出使用同一场景。
