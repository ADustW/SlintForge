# ForgePlot 日常交互性能复核

> 阶段记录：本文保留该组件实施时的范围、测试数量和验证结果；v0.1.1 当前能力见接入与交付说明，本次验收以时间戳发布目录中的 ACCEPTANCE.md 和 verification 为准。

日期：2026-10-03。根据用户反馈，复查日常 Gallery 中的卡顿，并将菜单入口直接放在“图表”下面。

## 发现与修复

1. 上一轮主要测量大数据场景计算和单次截图，未覆盖连续悬停、拖动、滚轮及实时刷新。此次在与 Gallery 共用的 `ProfessionalPlotDemo` 上派发真实窗口事件，并捕获完整窗口。
2. Slint 软件渲染路径在覆盖层移动时重复将 SVG 栅格化。两端绑定改用当前场景的像素图像；场景、尺寸或 DPI 变化时更新。缓存保留一幅图像，SVG/PDF 与位图导出继续使用原始逻辑尺寸。鼠标坐标查询也消除一次重复调用。
3. Rust 常用 Debug 构建中的绘制依赖没有优化。Gallery 与独立示例的外部依赖启用优化；项目代码保留 Debug 调试信息，共用 C++ 引擎采用 O2。
4. 共用引擎改用固定精度 `to_chars` 序列化坐标；密集折线的散点符号按屏幕网格去重。折线顶点、误差、选中点及原始索引命中不受符号去重影响。
5. `chart-professional` 的父节点为 `chart`，两种语言的名称均为 `ForgePlot`，并排在该菜单第一项。首页入口与稳定路由继续可用；导航目录及文档已同步。

## 连续交互测量

Windows x64、Slint 1.18.0、`winit-software`、1080×760 真实窗口。每组 24 帧，16 个“宿主 × 工作负载 × 操作”组合，共 384 帧；修改前后采用相同事件序列。最终测量时停止编译任务，避免 CPU 竞争。Rust 比较 Debug 与更新后的 Debug；C++ 比较同一 Slint SDK 下的 Release 构建，修改前 SDK 使用上一轮固定安装产物。

下表为事件处理、场景计算及完整窗口截图合计的中位耗时，不作为显示器呈现帧率。默认页面初始为 12 点；密集工作负载包含 2000 个测量点与 6 个参考点。

| 宿主与工作负载 | 操作 | 修改前 / ms | 修改后 / ms | 降低 |
|---|---|---:|---:|---:|
| Rust Debug，默认页面 | 悬停 | 458.13 | 7.42 | 98.4% |
| Rust Debug，默认页面 | 拖动 | 470.69 | 28.77 | 93.9% |
| Rust Debug，2000 点 | 拖动 | 569.55 | 42.53 | 92.5% |
| Rust Debug，2000 点 | 实时更新 | 573.46 | 42.74 | 92.5% |
| C++ Release，默认页面 | 悬停 | 17.35 | 4.64 | 73.2% |
| C++ Release，2000 点 | 悬停 | 26.51 | 4.92 | 81.5% |
| C++ Release，2000 点 | 拖动 | 67.15 | 28.88 | 57.0% |
| C++ Release，2000 点 | 实时更新 | 77.64 | 29.61 | 61.9% |

C++ 默认小数据的拖动从 18.86 ms 变为 20.57 ms：缓存的主要收益来自悬停与密集数据，场景变化仍需栅格化，不能将所有操作都描述成改善。当前密集场景的完整截图帧仍超过 16 ms，没有宣称达到固定 60 FPS。

完整数据位于 `build/plot-performance-qa/{before-rust-debug,before-cpp-release,final-rust-debug,final-cpp-release}/interaction-performance.csv`；汇总为 `performance-summary.json`，可用 `tools/verify_plot_performance.py` 重跑检查。本机阈值为悬停 P95 ≤15 ms、小数据其他操作 P95 ≤35 ms、密集数据其他操作 P95 ≤50 ms；阈值可通过命令行调整，不能外推到其他机器或后端。

## 回归与证据

- Rust 交互测试覆盖点击选择、图例、滚轮、平移、框选、禁用开关及导出；新增悬停复用同一图像、DPI 1→2→1 更新缓存，以及矢量尺寸不随 DPI 变化的断言。
- C++ 引擎测试新增密集符号压缩、折线顶点保留及未显示符号对应原始索引的命中断言。
- 两端常用 Gallery 重新编译；八个图表页面按中文深色、英文大字号、窄窗口和操作状态捕获。实际查看 ForgePlot 页面，确认菜单直接显示“图表 → ForgePlot”，曲线、图元、坐标和图例正常。
- 独立消费者遍历十种场景及五种导出格式；检查共享契约、导航目录、译文、66 段示例编译和第一方 C++ namespace 规则。

结果：Rust 20 项 SDK、2 项 Gallery、1 项组件交互、1 项独立示例测试均通过；C++ 图表核心 CTest 通过。两端 Gallery 各 32 帧，共 64 帧；56 帧基础图表的 160 个图例项通过实际像素对齐检查。16 组连续交互的 384 帧数据通过性能回归检查。

当前复核目录为 `build/plot-performance-qa`；此前 `build/plot-qa` 和 `build/gallery-followup-qa` 的固定记录保留用于前后比较。
