# ForgeFlow 连线专项审查（2026-10-14）

本轮针对密集卡片遮线、一个节点连接多条线、跨行连接末端只见箭头的问题，在正式仓库内修复共享核心和 Slint 绘制组件，保留既有未提交修改。没有新增公共字段或运行库操作号，Flow 契约仍为 13。

## 查明的问题与修复

| 问题 | 原因与处理 |
| --- | --- |
| 长线与箭头脱开 | Slint `Path` 按描边宽度缩小可用视框，线身、选择光晕和箭头使用了不同的缩放。为描边补回尺寸和位置，并显式使用 `fit: fill`，使绘制与命中几何一致。旧版本固定长粗线场景有 112 列像素缺口，细线也有缺口。 |
| 密集卡片盖住粗线边缘 | 旧避障只检查中心线。现在给非端点卡片预留描边半径和额外间距；圆角生成后再次检查碰撞，必要时缩小圆角。24 组固定随机布局、288 条边中，旧版本发现 61 处描边侵入，新路径检查为 0 处。 |
| 自动直线穿过中间卡片 | 自动直线现在优先直连，受阻时使用折线路径；移动非相邻障碍物也会使其缓存失效。严格直连仍可用空控制点的手工 `polyline` 表达。 |
| 共用端口形成长段重合 | 按端口和稳定连线 ID 分配引出距离，一对多、多对一靠近端口分流。隐藏连线不占用自动通道，删除、撤销后分配可重复。 |
| 近距离并行边折回原路 | 相向端口的引出点重合时，缩短引出段，保留两个独立转弯点。 |
| 分组标题末端漏算 | 修正分组标题底部 8 个逻辑像素未进入障碍物范围的问题。 |
| 换文档后旧卡片内容覆盖连线 | 实际 Skia 软件窗口复现了旧表单／图片残留，且内容伸出新卡片。撤下正文 `cache-rendering-hint`，保留正文裁剪、输入控件及点阵优化。 |

Slint 视框行为同时核对了本机 1.18.0 源码和[官方 Path 文档](https://docs.slint.dev/latest/docs/slint/reference/elements/path/)。修复保留世界坐标路径格式，导出、标签、动画和命中继续使用同一份核心几何。

## 验证

核心新增固定密集布局、描边净空、一对多／多对一独立命中、删除撤销恢复、非相邻节点移动、分组标题和近距离并行线测试，并运行已有四边端口方向、重连、手工控制点、样式、分组、历史与导出测试。

窗口入口为 `tools/windows/Test-FlowRouting.ps1`。53 步专项场景覆盖长线、实心／空心箭头、粗细线、选中光晕、缩放、深浅主题、多分支、近距离并行线、密集图及跨行窄窗口，并检查真实截图中的线身连续性。矩阵包含 C++／Rust、`winit-skia`／`winit-skia-software` 和 `SLINT_SCALE_FACTOR=1/1.5/2`；这里是应用显示比例验证，不代表更换了 Windows 系统 DPI 设置。

本轮证据目录：`build/flow-routing-review-20261014/`。最终结果以该目录的 `result.json` 为准；失败和修复前截图另行保留，不覆盖为成功结果。

最终验证全部通过：12 个窗口组合、96 项线身连续性检查，双端各 52 步既有连线编辑、75 步细化交互和 234 步高级编辑回归，双端卡片输入／弹层／主题重绘检查，Gallery 五页（每端 15 个状态）、公共 SDK 契约、Rust 4 项 Flow 测试和 4 项 DLL 测试。动画及 SVG／PNG 导出检查通过。Release 核心测试在 500 节点／1000 连线下的操作 P95 为 2.48ms；该数字不包含窗口绘制耗时。

## 连接规则与边界

- 默认拒绝悬空引用、自连接和重复同端口连接；容量、方向和业务校验沿用已有策略。通用图允许环，思维导图保持树约束。
- 自动曲线／折线绕开卡片，直线模式受阻时绕行；手工路径保持开发者设置。
- 共享端口可以有短段重合，不同连线仍可能交叉；本次没有实现全图无交叉布线或交叉桥。
- 卡片重叠堵住端口，或通道小于线宽时，不能保证完全可见。窄通道会缩减留白；完全封堵时保留连接，需移开卡片或减小线宽。
- 本轮撤下了卡片正文缓存，因此更早的缓存版本数字不代表当前版本。随后同一产物的独立性能复核见 `build/flow-performance-resumed2-20261014/result.json`，当时内存峰值约 901／902MiB。最新增量历史优化见 `FLOW_HISTORY_MEMORY.md`：C++／Rust 峰值降至 471.84／458.48MiB，三轮有效性能场景 12/12 达标，最差帧 P95 26.8031ms。C++ 帧数据使用 OpenGL，Rust 使用 DX12；核心操作计时与整帧耗时含义不同。
