# ForgeFlow 增量历史与内存预算验证

日期：2026-10-14。工作目录：`D:/ai_workspace/SlintForge/SlintForge`。本次仅优化 Flow 的编辑历史、事务临时复制及对应 SDK 接口，保留工作区其他改动和正文缓存回退。

## 实现

原历史每一步保存整份文档内容，100 步大图编辑会重复保留相同节点、连线和业务数据。本次由 `sdk/common/ForgeFlowHistory.hpp` 保存稳定 ID 下的双向字段差量，并编码为 CBOR。新增／删除仅保存受影响元素及位置，重排才额外记录顺序；撤销和重做复用同一条记录。

命令入口统一提交历史，连续拖动和批量事务各占一步。事务不再复制整个控制器及其几何／历史缓存，保存点比较也不再生成整图临时副本。活动文档、保存点和单次事务／手势仍保留恢复所需的数据。

默认最多 100 步、32 MiB，撤销与重做共同占用该预算。C++／Rust 公共接口为 `configure_history(max_steps, max_bytes)` 和 `history_status()`。配置属于单个控制器，不进入文档或历史；加载新文档清空历史并保留预算。详细字段和范围见 [Flow 接入文档](FLOW.md#增量撤销与内存预算)。

缩小预算优先移除最早撤销记录，再移除最远重做记录，保留连续可达的历史。单次修改超过预算仍正常生效，但清空两端历史建立边界，防止跨过未记录的修改。新分支释放重做记录；无变化、失败命令、选择和视口移动不消费历史。

Flow 契约更新为 14，已重新生成接口指纹；操作号和 Slint 公共结构保持不变。Rust 应使用本次配套 DLL，旧 DLL 会被加载器拒绝。没有引入新的第三方依赖。
