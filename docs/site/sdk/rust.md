# Rust SDK

Rust SDK 覆盖路由、导航树、截图、图标、瀑布流、Widget 服务、Grid、Plot、Flow、运行库初始化、窗口边角和构建集成。

## 模块

- `sdk/rust/src/capture.rs`
- `sdk/rust/src/color.rs`
- `sdk/rust/src/flow.rs`
- `sdk/rust/src/flow_bindings.rs`
- `sdk/rust/src/flow_export.rs`
- `sdk/rust/src/grids.rs`
- `sdk/rust/src/icons.rs`
- `sdk/rust/src/lib.rs`
- `sdk/rust/src/plot.rs`
- `sdk/rust/src/plot_bindings.rs`
- `sdk/rust/src/plot_ffi.rs`
- `sdk/rust/src/runtime.rs`
- `sdk/rust/src/staggered_layout.rs`
- `sdk/rust/src/widgets.rs`
- `sdk/rust/src/window_corners.rs`
- `sdk/rust/src/wire.rs`
